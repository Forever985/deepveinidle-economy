利润网：修完类型检查，构建通过

首次真实执行 npm install + vue-tsc + vite build，暴露并修掉 22 处类型问题。

关键修复
- **App.vue 的相对导入写错了**：它在 src/ 下，我写成 '../api/...'，
  实际解析到 web/api（不存在）。这会让构建直接失败。
- 我把 `type` 当成具名导入了 —— 它是 TS 内建关键字，不是模块导出。
  GameData 类型改从 './types' 用 import type 取。
- tsconfig 开 allowImportingTsExtensions：
  calc/ 里的导入带 .ts 后缀是为了让 Node 的类型剥离模式能跑，
  这是刻意为之，所以开这个开关而不是改导入写法。
- 装 @types/node 并加进 types（测试要用 node:fs / process）。
- 清掉一批未使用的私有字段（构造函数参数属性改成显式字段后残留的）。

环境相关的两个坑
- **npm 默认 registry 是 npmjs.org，国内极慢** → web/.npmrc 配 npmmirror，
  与 milkonomy 一致；这个文件也会被 GitHub Actions 读取。
- **esbuild 的 postinstall 被 npm 11+ 拦截**（install-scripts 未批准），
  但实测不影响构建，esbuild 的 wasm 兜底可用。

构建结果
dist/ 共 4 个文件，约 100 KB（JS gzip 后 37 KB）。
**资源路径是相对的（./assets/...）** —— GitHub Pages 挂在子路径下，
用绝对路径会全 404，这是 base:'./' 的目的。

测试 68/68 通过。
