# DVI Tools

面向网页游戏 **Deep Vein Idle**（https://deepveinidle.com/ ）的一套**只读**增强工具。

设计参照 MWITools 的思路：**把信息就地长在游戏界面里**，而不是另开一个悬浮窗。

---

## 只读，且仅此而已

这不是一个自动化工具，是一条**架构级约束**：

- **不发送任何游戏指令。** 网络层刻意不暴露 `send`，插件上下文里
  `ctx.core.net.send === undefined`。有断言守着这条线。
- **不读他人隐私。** 采集类脚本在**源头**丢弃聊天 / 私聊 / 公会频道 / 其他玩家信息，
  字段用**白名单**而非黑名单。
- **不做自动化。** 服务端有封禁机制（WS 关闭码 4002 = banned），
  且游戏是单世界共享经济。
- 所有导出走**下载文件**，不使用剪贴板。

## 装什么

| 文件 | 用途 |
|---|---|
| **`dvi-tools/dvi-tools.user.js`** | **唯一需要安装的文件**（主干 + 插件已打包在一起） |
| `dvi-tools/dvi-check.user.js` | 最小自检脚本，诊断用，装完可删 |
| `dvi_probe/dvi-collector.user.js` | 数据采集器，开发用。**默认不记录**，普通使用不需要 |

安装方式：把 `.user.js` 拖进浏览器（需已安装 Tampermonkey），
或复制内容到 Tampermonkey 新建脚本。

**安装后请确认版本号是最新的** —— 版本号是日期式（如 `2026.10.03.1`），
一眼就能分辨新旧。

## 现在能做什么

在游戏的作业列表里，**每一行末尾就地显示**「还需几次行动才能升级」：

```
Copper  ▸ 需 128 次 · 3 分 12 秒     ← 悬停可看：分段明细 + 当前配置
```

悬停提示里会如实列出这次计算用到的**实时参数**（等级、当前装备、
特长、增益、社区活动倍率），让你看得见数字从哪来。

### 按需刷新，不是每帧重算

**计算比重新注入贵得多**，所以拆成两件事：

| | 频率 | 成本 |
|---|---|---|
| 重新注入 | 高（游戏每次重绘都会触发） | 只读缓存，几乎为零 |
| 重新计算 | 低（只在需要时） | 逐级累加经验 |

触发重算的方式（任选）：

- 点作业列表上方的 **「重算预估」** 小按钮
- 刷新页面
- 油猴菜单 → **「🔄 重算并刷新（按需）」**
- 想自动：把插件的「刷新方式」设为 `1`（状态变化后最多 30 秒重算一次）

## 自行构建

```bash
cd dvi-tools
python build.py                 # 内联游戏数据 + 注入插件 → 单个用户脚本
node --check dvi-tools.user.js  # 独立语法校验
node test/test.js               # 全部断言
```

`build.py` 会在结构不完整时**直接中止**，不产出不可信的产物。

### 游戏改版后

平衡常量全部走数据层，**逻辑代码不用改**：

```bash
cd dvi_probe
python extract_balance.py       # 从 bundle 重新提取系数表
cd ../dvi-tools && python build.py
```

```

├── plugins/
│   ├── 10-example-job-yield.js    示例插件

├── dvi-collector.user.js        数据采集器
└── simulate.py                  模拟数据生成器
```

> **不入库**，见 `.gitignore`。
